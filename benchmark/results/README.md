# Benchmark results

Reviewed, promoted results. Everything here is a **deliberate copy** from
`runs/`, promoted after review — never an automatic sync.

## What belongs here

- A result that answered a question worth remembering.
- The run manifest that produced it (case ID, Git commit, runtime version, DSH
  version, model, model configuration, prompt versions, schema versions, source
  bundle, timestamp — `AGENTS.md` §9).
- The human judgment attached to it, including a rejection.

## Rules

- One file or directory per promoted result, named so the case and date are
  obvious.
- A promoted result is immutable. A re-run produces a new entry; it does not
  overwrite the old one.
- Rejected or inconclusive results are worth keeping when they explain a design
  choice. Note the reason.
- Do not promote raw, unreviewed output. `runs/` is where raw output lives.
