# Human Note 写作：看懂大意，留好入口

## 1. 覆盖范围与展开程度分开

完整读懂本批授权资料，不等于将每个细节写进笔记。正文让读者认出重要知识点、知道大意、辨认关键差别；需要深入时能通过已有知识链接或原始材料定位继续查。省略展开不等于原始证据被丢弃，也不等于知识不确定。

| 展开程度 | 写法 |
| --- | --- |
| 简明提要（推荐） | 一个术语加一句大意；确有必要再加条件、用途、区别或核心公式。短语、分点、小表格均可。 |
| 重点解释 | 仍以提要为主，只对难懂、易混或用户指定的内容多解释几句；必要时保留一个有区分作用的原例。 |
| 详细整理 | 按用户要求保留材料支持的推导、步骤与例子；去重，仍不补课本式外延知识。 |

“AI 自行取舍”从简明开始，不自动升级为详解。旧偏好的映射与当前用户要求的优先级见 SKILL.md。不要机械规定每个知识点的字数、句数或栏目数，也不要为缩短字数挤成难以理解的术语堆。

## 2. 哪些值得写

- **主体**：本批主题中的重要概念及其简要含义；能区分它与相近概念的特征。
- **必须随概念保留**：省略后会变错或产生明显误解的条件、否定、适用范围、单位和必要符号含义。写了公式，就保留理解它所需的条件；不用自动附完整推导。
- **按需保留**：没有它就很难看懂的原例、关键操作步骤、确有新信息的比较或限制。可读懂时不再堆同类例子或完整教学过程。
- **通常不展开**：重复解释、铺垫、过渡总结、同义改写、配套教材中的外围段落。不是每个点都要“定义—原理—例子—应用—易错点”。

先写能让人辨认和检索的最小充分说明，再判断是否仍有实质歧义。若一句额外说明既不改变含义、适用条件或区分度，也不帮助定位，不必加入。不能把全部内容塞到折叠块、附录或另一份详细版来假装精简。

原资料明确强调的独特方法、边界或结论仍需保留其大意，不能仅因它不是定义就丢掉。例题在提要中可只留题型及关键做法；用户要做题讲解或完整题解时，才保留完整题设与必要步骤，不能给一段无法使用的半截题解。

## 3. 如何表达与连接

- 直接写知识。允许短语、省略句和小标题下的一两行说明；省掉“为了帮助理解”“老师进一步指出”等引入。
- 比较用小表格或相邻短句；必要流程才用有序步骤。箭头只能表达材料支持的关系，不能代替含义不明的因果说明。
- 正文已有含义清楚的段落，就不用再添加同义的“总结”“核心要点”“一句话理解”。二级标题仍连续编号；不要把每条短句都拆成页面或独立标题。
- 对已存在且已确认的知识页使用 wikilink，链接代替重复复制它的详解。没有现成页面时保留准确术语，必要时加一个材料中已有的同义词，便于用户自行搜索；不伪造链接，不因提到术语就创建空页。
- 有助理解的原图仍可使用；纯文字截图或图文重复堆叠不能代替内容选择。

## 4. 多份材料与持续生长

用户提供课堂资料加配套教材时，默认围绕本次课堂主题；教材用于材料内可核对的术语、必要条件和指定难点，不自动把整章知识并入正文。用户明确要求教材专题整理或各文件并重时，按其指定范围覆盖，仍遵循所选展开程度。

旧笔记已表达同一含义，就复用并补来源；仅出现新条件、实质区别或新知识时才改正文。用户手工整理的有效内容不能因这次偏好简明就静默删掉。不得仅为缩短当前页面迁移旧段落、拆出大量新页或建立另一份完整笔记。

AI 层继续保存简短对象、定位词、关系和原文位置，不接收所有从正文省略的段落。重要但未展开的内容通过紧凑来源定位保留检索入口。只有资料确实缺失或不确定时才标记 deferred；“未展开”不能被写成“未知”或“已有知识已完全覆盖”。

## 5. 写法示例

以下是独立的格式示例；实际笔记只可使用用户材料支持的内容，也不要求每个点都长成同一格式。

示例材料：条件概率是在事件 B 已发生的条件下考虑 A 的概率；公式为 P(A∩B)/P(B)，要求 P(B)>0。材料接着给出多个同类计算例题。

简明提要可以写成：

```markdown
## 1. 条件概率

已知 $B$ 发生，只在 $B$ 的范围内看 $A$。

$P(A\mid B)=P(A\cap B)/P(B)$，条件：$P(B)>0$。
```

无需自动接上逐题演算、课堂过渡和另一个同义总结；若其中某个例题揭示不同的适用条件，则保留该差别。只有术语、没有含义的“条件概率 / 交集 / 公式”也不合格。
