# WorkBuddy 连接器适配说明

本 Skill 是 **Skill-only** 能力包，不是连接器，也不自带账号授权、credentials 或远程服务。默认使用 WorkBuddy 已授权的本地工作目录；连接器只有在用户明确打开并授权后才参与当前任务。

## 可选连接器

| 连接器 | 适合用途 | 默认行为 |
| --- | --- | --- |
| ima 知识库（如果当前 WorkBuddy 连接器列表提供） | 读取选定知识库资料，或在用户确认后保存整理结果 | 不自动扫描整个知识库；只读取用户选中的库/文档；写回前再次确认 |
| 腾讯乐享知识库 | 团队资料检索、引用、创建或编辑知识库文档 | 作为可选团队知识源；不替代 AI Layer，除非用户明确指定写回位置 |
| 腾讯文档 / 腾讯网盘 | 选择原始资料或上传最终产物 | 只处理用户当前选定的文件；不当作课程知识网络的默认存储 |
| 自定义 MCP 连接器 | 用户已有的其它知识库或文件服务 | 仅在用户指定并完成授权后使用，按该连接器的工具说明执行 |

“ima 知识库”是否可用取决于 WorkBuddy 当前客户端、账号和连接器列表。Skill 不假设它一定存在；不可用时回退到授权本地目录。连接器的名称、权限和可用性以 WorkBuddy 当前界面为准。

## 推荐的读取与写回顺序

1. 先确认本次资料来自本地授权目录，还是来自某个已连接的知识库。
2. 如果使用知识库，只读取用户指定的知识库、文件或搜索范围，不做全库扫描。
3. 先生成 Human Note 和 AI Layer 的结果，并保留来源链接或文档 ID。
4. 在写回知识库、修改已有文档或覆盖页面前，向用户说明目标位置和改动范围，等待明确授权。
5. 写回失败时保留可下载的本地结果，不重复提交，也不把临时 JSON 写入知识库。

## 连接器边界

- Skill 不保存、打印或复制凭证；认证由 WorkBuddy 连接器管理。
- Skill 不主动定时抓取、后台同步或监视知识库。
- 连接器返回的相关性结果只是候选线索；知识内容仍须以用户提供的资料和可定位的已有笔记为依据。
- 连接器读到的内容也必须经过与本地资料相同的简明整理、公式检查、链接解析和增量更新规则。
- 如果连接器权限不足、文档不可读或搜索结果无法定位，标记缺口并停止对应写入，不凭模型记忆补齐。

## WorkBuddy 侧配置

连接器应在 WorkBuddy 的“专家·技能·连接器”中单独添加并授权，再在当前任务的工具面板启用。Skill 不应把某个连接器写成硬依赖；这样用户仍可只上传文件使用，也可以在需要时临时启用 ima 或腾讯乐享。
