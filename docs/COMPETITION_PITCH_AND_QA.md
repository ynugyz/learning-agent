# 个人赛作品说明与答辩问答初稿

> 这是内部准备材料，不是 PDF 规定的提交格式。比赛条款只依据用户提供的《安永校园AI创新挑战赛.pdf》。
> 任何性能数字、运行时长和质量比例都必须在实际运行后填写，不能用估计值。

## 一句话说明

Learning Agent 把课程转写、课件和已有笔记整理成可以继续生长的知识库：同一份材料同时生成给人复习的正式笔记和给 AI 后续检索的轻量知识层，并保留来源、链接、缺口和可回退边界。

## 30 秒开场

很多学习资料并不是没有内容，而是转写口语化、顺序跳跃，且每次使用 AI 都会生成一篇孤立摘要。已有笔记中的公式、例子和边界容易被覆盖，下一次也很难找到上一次写过的知识。

我做的 Learning Agent 面向这个学习资料整理痛点。用户提供一份材料，系统先读取有限的已有知识，再输出正式 Human Note 和紧凑 AI index/cards；第二次提供同主题材料时，它会扩展原有知识对象、增加有依据的双链，并把无法确认的内容保留为待补项，而不是自行补成事实。

## 现场演示顺序

1. 展示一份赛事模拟学习材料和一页已有知识。
2. 指定 Human 与 AI 输出目录，运行第一次编译。
3. 打开正式 Human Note：展示定义、机制、公式、例子、边界和已有链接。
4. 打开 AI index/cards：展示稳定对象、来源、关系和更新状态。
5. 输入同主题补充材料，运行第二次编译。
6. 展示同一知识对象被扩展、旧内容保留、双链增加，以及前后 diff。
7. 展示一条证据不足的内容被 deferred；展示验证报告和回退位置。

现场只展示已经人工审阅的结果。开发合成 fixture 不能冒充赛事提供的模拟数据；正式演示输入必须符合 PDF 的数据要求。

## 作品亮点

| 亮点 | 可展示证据 |
| --- | --- |
| 持续生长 | 两次输入命中同一知识对象，第二次生成更新 diff |
| 双层输出 | Human Note 与 AI index/cards 具有稳定对应关系 |
| 来源约束 | 新增内容能回到材料或已有有效笔记；无法确认的内容进入 deferred |
| 知识连接 | 只对已加载且可解析的已有页面建立 `[[wikilink]]` |
| 安全边界 | 使用有限快照，不扫描整个 Vault，不直接覆盖生产笔记 |
| 可回退 | 输出更新前后 hash、manifest 和审阅记录 |

## 常见问题

### 它和普通摘要器有什么区别？

普通摘要通常只处理当前输入，结果是一篇孤立文本。这个工具把已有有效笔记作为受限 Knowledge State，判断新材料是新增、扩展、修正、例子、关系或暂缓，并分别维护 Human 与 AI 两层，使下一次输入能继续找到同一个知识对象。

### 它会不会把课堂观点写成事实？

不会把没有来源支持的内容自动升级为客观事实。教师观点、类比、术语不稳、缺失公式和证据冲突会保留其语境或标记 deferred；正式笔记只接收能回到输入材料或已有有效笔记的内容。

### 为什么需要 AI 层？

Human Note 适合阅读和复习，不能承担全部检索索引。AI 层只保留稳定知识身份、别名、页面定位、关系、来源和更新状态，后续先查小索引和卡片，再按需打开 Human Note 和原始材料，减少重复读取。

### 会不会覆盖已有笔记？

默认先生成隔离的候选更新和 diff。只有用户审阅后才接受写入；运行失败或不确定时保留诊断并回到运行前状态。正式演示不直接写入 Production Vault。

### 它现在是独立桌面软件吗？

当前正式入口是 Codex Skill，不宣称是独立桌面应用或 Obsidian 插件。比赛演示应如实说明运行环境；如果赛事要求独立运行，再单独确认包装方式，不把未完成能力说成已有功能。

### Codex 在作品中做了什么？

核心问题、知识组织思路、Human/AI 双层目标和 SourceMap、LessonModel、Alignment、ChangePlan 四类基础职责由参赛者提出。Codex 负责把这些想法整理为 Skill、量化检查、验证流程、代码和文档，并协助测试；数据选择、结果审阅和提交由参赛者决定。

### 为什么不用真实课堂或生产 Vault？

PDF 明确要求使用赛事提供的模拟数据，并禁止企业或客户真实敏感数据。个人课程材料和生产 Vault 也不进入公开提交包；现场只使用符合赛事要求的模拟材料。

### 官方评分标准和提交格式是什么？

用户提供的 PDF 没有给出统一量化评分表、正式提交格式或截止时间。答辩中不猜测这些内容，待赛事后续通知或人工确认后再填写。

## 不应在答辩中说的话

- “已经完全自动化，不需要人工审阅。”
- “准确率、节省 Token 或运行速度提升了 X%”，除非指标模板中有实际运行证据。
- “可以在任何电脑独立运行”，当前产品仍依赖 Codex Skill 环境。
- “使用了真实课堂、企业或客户数据”，正式演示必须使用赛事模拟数据。
- “这是 Obsidian 官方插件”，当前不是。
