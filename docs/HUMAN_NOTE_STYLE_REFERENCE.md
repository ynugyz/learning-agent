# Human Note v2 Style Reference

这是 Human Note Presentation Layer 的短样例。它描述复习时的视觉边界，不是正式 schema。

## 三个独立 recall targets

**Bad**：把三大流派、混合增强和学习建议揉成一个长段。

**Good**：

### 符号主义

用显式规则和逻辑表示知识。规则明确，但复杂知识下难以穷尽。

### 连接主义

用数据学习表示，以神经网络为主要路线。

### 行为主义

通过环境交互和反馈学习行为。婴儿学步是“行动 → 反馈 → 调整”的课堂类比。

### 混合增强人工智能

模型负责理解、对答和规划，skill、插件、Harness、Agent 等组件负责补充能力、执行和数据流转。

### 领域定位建议

教师建议学生先找本领域痛点，再用 AI 做赋能与服务。

三个路线是知识块，混合增强是工程形态，领域定位是教师建议；它们需要分别定位。

## 课堂真实展开

**Bad**：现代系统经常组合使用。

**Good**：现代 AI 系统常采用组合方式：模型负责理解、对答和规划，组件负责补充能力、执行和数据流转。课堂还提到机械臂、外骨骼等未来可能接入的物理载体。

篇幅取决于独立信息数量，不取决于转写字数。

## 例子不单独碎块

### 行为主义

通过环境交互和反馈学习行为。婴儿学步是“行动 → 反馈 → 调整”的课堂类比。

“婴儿学步”服务行为主义这个 recall target，不另建标题。

## 关系静默

### 知识图谱

知识图谱用图结构组织实体及关系。

### 概率图

现实关系并不总是确定成立，因此概率图表示关系中的不确定性。

不要把课堂顺序写成“前者为后者奠定基础”的关系作文，除非因果关系本身是课堂知识。
