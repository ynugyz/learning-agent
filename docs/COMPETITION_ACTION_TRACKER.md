# 参赛行动清单

本清单只依据 `安永校园AI创新挑战赛.pdf`。所有状态均以证据文件为准；没有证据的项目不能标记为完成。

## A. 必须由参赛者确认

- [ ] 选择个人赛或团体赛，且不双线报名。
- [ ] 确认 2026 年 9 月在读年级符合要求。
- [ ] 团体赛确认 2–4 人和队员变更规则。
- [ ] 个人赛确认主题属于学习/生活效率工具；或团体赛拿到安永业务场景包。
- [ ] 确认作品独立完成，没有代做或外购成品。
- [ ] 向主办方确认 Codex 的开发辅助边界和披露方式。
- [ ] 确认演示只能使用赛事模拟数据，或确认允许的替代数据类型。
- [ ] 确认是否允许展示脱敏课堂材料；默认不上传真实课堂录音、旧笔记和生产 Vault。
- [ ] 确认非商用展示、案例收录和作品著作权安排。
- [ ] 确认报名、提交、演示和现场评审的具体时间与格式。

## C. 公开 benchmark 最低结构

```text
benchmark/cases/competition-demo/
├─ README.md
├─ case-01-noisy-transcript/
│  ├─ input/
│  ├─ gold/
│  └─ expected.md
├─ case-02-existing-note-growth/
│  ├─ input/
│  ├─ gold/
│  └─ expected.md
└─ case-03-repeat-example-and-link/
   ├─ input/
   ├─ gold/
   └─ expected.md
```

Gold 必须由参赛者确认。Agent 可以整理标注格式和计算覆盖率，但不能自行决定“正确笔记应该写什么”。

## D. 终端演示顺序

1. 选中脱敏输入和已有页面。
2. 指定 Human 和 AI 输出位置。
3. 运行第一次编译。
4. 展示正式 Human Note、AI index/cards、来源和验证。
5. 再提交一段补充材料。
6. 展示同一知识对象被扩展、原页面保留、双链增加。
7. 展示一项缺失证据被 deferred。
8. 展示 diff、回退边界和“生产 Vault 未写入”。

## E. 提交前检查

- [ ] 仓库没有真实课程笔记、录音、企业数据、个人信息或 API Key。
- [ ] 所有截图和素材均为合成、脱敏或已授权内容。
- [ ] README 的命令在干净环境中能执行。
- [ ] 公开分支或 tag 已明确。
- [ ] LICENSE 已由参赛者确认。
- [ ] 所有性能和质量数字能回到运行 manifest。
- [ ] 演示材料没有把候选、历史实验或未验证功能说成正式能力。
- [ ] 参赛者已检查作品原创性、第三方素材许可和安永展示授权。
- [ ] 表单、视频、幻灯片和最终压缩包已由参赛者人工上传。
